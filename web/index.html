Is it significant · method and validation

How the tool decides a change is real

Per cell

  1. Remove the seasonal cycle (monthly climatology).
  2. Size: Theil-Sen slope with a rank confidence interval.
  3. Significance: Mann-Kendall with the Hamed-Rao autocorrelation correction, rank ACF modelled as AR(1).
  4. Cross-check: OLS with an AR(1) effective sample size (Santer et al. 2000). Disagreement is shown, not hidden.
  5. Detectability: Weatherhead et al. (1998) smallest detectable trend and years needed. "No trend" becomes "not yet detectable" when the record is too short.
  6. Homogeneity: a step test at every documented data-source change (instrument switch, reanalysis stream).

Across the map

  • Benjamini-Hochberg false discovery rate over all valid cells, with αFDR = 2 × αglobal for spatially correlated fields (Wilks 2016).
  • Cells with missing months are excluded, never gap-filled, and the tool says why.
  • Connected regions of significant increase and decrease are listed so opposite-sign changes in the same variable stand out.
  • Every number on this page can be recomputed with python -m trend_detective build.
